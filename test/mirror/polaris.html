Polaris references

Shopify apps can appear across multiple surfaces in the Shopify platform. Each surface has its own set of available APIs and components. For an overview of all surfaces and how to build apps for them, see App surfaces.

All app surfaces use Polaris, Shopify's unified UI framework built on web components, to deliver a consistent experience across the platform.
