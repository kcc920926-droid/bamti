# 밤티 사용 용례 — 바이럴 스크린샷

최종 파일: **`bamti-use-case.png` (2400 × 2028 PNG)**

콘셉트: **AI가 만든 내 사이트, 배포해도 괜찮을까?**

`slop-demo.html`은 이번 촬영을 위해 작성한 가상 랜딩페이지입니다. 보라색 그라디언트,
범용 카피, 동일한 3열 카드, 더미 문구와 빈 링크를 의도적으로 넣었습니다.
고객 수와 고객 회사명은 사실이나 추천사가 아닙니다.

검사 시점 결과는 **77/100, 검토 신호 17개, 빈 링크 목적지 6개**입니다.
`scan-report.json`은 해당 DOM을 실제 `context.js`, `signals.js`, `score.js`, `scan.js`로
분석한 결과이며 점수·근거·개선 방향을 수작업으로 바꾸지 않았습니다.
점수는 AI 생성 확률이나 전반적인 정확도 평가가 아닙니다.

이미지는 홍보용 제목과 브라우저 모양의 프레임 안에 실제 예시 페이지·밤티 패널을 렌더링한
**데모 구성 캡처**입니다. 네이티브 크롬 창 전체를 찍은 사진은 아닙니다.
`panel.html`은 확장 API의 전달 경로만 모의 실행하고 현재 프로젝트의 실제 패널 HTML/CSS/JS를
그대로 불러옵니다. 미완성 카테고리를 선택하고, 항목을 펼친 다음, 빈 링크의 위치 표시 버튼을
클릭했습니다. 오버레이도 제품 코드 그대로입니다. 이미지 생성 도구로 UI를 그리지 않았습니다.

## 재현

프로젝트 루트에서 로컬 서버를 실행합니다.

```sh
python3 -m http.server 8777 --bind 127.0.0.1
```

Playwright와 Chromium을 사용할 수 있는 Node 환경에서:

```sh
node asset/viral/capture.cjs
```

다른 주소를 쓰면 `BAMTI_DEMO_URL`로 지정할 수 있습니다. 캡처 스크립트는 로컬 출처 외의
네트워크 요청을 차단하고, 페이지 오류·엔진 오류가 없는지 검사한 뒤 PNG와 JSON을 저장합니다.
엔진 또는 패널이 바뀌면 점수와 화면도 바뀔 수 있으므로 이미지를 다시 촬영하세요.

제목·프레임: `index.html` / 예시 페이지: `slop-demo.html` / 실제 패널 연결: `panel.html`.
외부 공개나 배포는 하지 않았습니다.
