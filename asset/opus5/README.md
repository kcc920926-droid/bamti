# 부품 대장 (Parts Ledger)

화면을 만들 때 꺼내 쓰는 부품 **102종**을 한 문서에 모은 규격서.
견본만 늘어놓지 않고 부품마다 **요소 · 상태 · 키보드 · 금지**를 함께 적었다.

```
open index.html          # 그대로 열면 동작한다 (빌드·서버·설치 없음)
```

## 무엇이 들어 있나

| 장 | 이름 | 부품 |
|---|---|---:|
| 01 | 기초 — 색·활자·간격·모서리·들림·움직임·아이콘·층위 | 9 |
| 02 | 동작 — 버튼 계열 | 10 |
| 03 | 입력 — 값을 받는 부품 전종 | 23 |
| 04 | 이동 — 내비게이션 | 9 |
| 05 | 표시 — 표·목록·그림표·배지 | 19 |
| 06 | 알림 — 알림 상자·조각·진행·뼈대 | 9 |
| 07 | 겹침 — 모달·서랍·팝오버·초점 규칙 | 6 |
| 08 | 담기 — 카드·접이식·도구줄·판 | 9 |
| 09 | 조합 — 여러 부품을 한 화면에 놓은 예 | 5 |
| 10 | 부록 — 접근성 점검표·키보드 지도·판 이력 | 3 |

전부 실제로 동작한다. 정렬되는 표, 초점을 가두는 모달, 붙여넣기를 나눠 담는 인증번호 칸,
키보드로도 옮겨지는 목록과 작업 판, 데이터에서 그려지는 그림표까지.

## 설계에서 정한 것

**종이와 잉크.** 따뜻한 종이색 바닥에 먹색 글자, 강조는 청록 하나. 상태색(성공·주의·위험·안내)은
뜻이 있을 때만 꺼낸다. 층은 그림자보다 1px 선으로 나눈다 — 그림자는 실제로 떠 있는 것에만.

**세 벌의 활자.** 제목은 세리프, 본문과 조작부는 산세리프, 숫자와 코드는 고정폭.
장식이 아니라 역할 구분이다. 크기는 9단계에서 끝낸다.

**각이 기본.** 둥글기는 위계를 만들 때만 쓴다 — 조작하는 것 4px, 담는 것 8px, 알약은 상태 표시에만.

**세 층의 토큰.** 원시값(`--teal-1`) → 역할(`--accent`) → 부품. 부품 CSS는 원시값을 모른다.
그래서 어두운 배색용 CSS가 따로 없다. `data-theme`과 `prefers-color-scheme`이 역할 층만 바꾼다.

**토글은 필요한 것만.** 배색은 밝게/기기 설정/어둡게 3단, 밀도는 보통/촘촘 2단.
둘 다 `localStorage`에 남고, 표와 목록이 많은 화면을 위해 밀도가 실제로 치수를 바꾼다.

## 접근성

부록 10.01의 열 줄을 부품마다 지켰다. 요약하면:

- 모든 동작이 키보드만으로 된다. 탭·분절·별점·나무·달력·작업 판 모두 화살표로 다룬다.
- 겹침 부품은 초점을 가두고 되돌린다. 모달·서랍·판은 네이티브 `<dialog>` — 브라우저가 처리한다.
- 상태 변화는 `aria-live`로 알린다 (정렬·이동·복사·검사 결과).
- 뜻을 색만으로 전하지 않는다. 배지는 점, 알림은 아이콘, 오류는 글자를 함께 쓴다.
- `prefers-reduced-motion`에서 모든 전환이 즉시 끝난다.

## 구조

```
index.html          문서 전체 · 아이콘 한 벌(<symbol>) 포함
css/tokens.css      ★ 색·활자·간격·모서리·움직임 토큰. 여기서 시작한다
css/base.css        초기화 · 활자 · 페이지 골격(레일·도구줄·장)
css/controls.css    조작부 — 버튼과 입력
css/surfaces.css    면 — 이동·표시·알림·겹침·담기
css/docs.css        문서 장치 — 부품 카드·시연 무대·규격표·견본
src/main.ts         ★ 동작. 부품마다 data 속성을 훑어 붙인다
src/main.js         컴파일 결과 (문서가 실제로 읽는 파일)
og.svg              공유 카드 이미지
```

## 고칠 때

```bash
npx tsc -p tsconfig.json     # main.ts → main.js
```

`strict` + `noUncheckedIndexedAccess`로 검사한다. 외부 패키지는 쓰지 않는다.

부품을 추가할 때는 `<article class="part" data-part data-name="이름 영문 검색어" id="p-...">`에
규격표(`<dl class="spec">`)까지 채운다. `data-name`이 걸러내기·명령 팔레트·자동완성의 색인이 되므로
검색될 낱말을 함께 적는다. 규격표의 네 줄(요소·상태·키보드·금지)이 없으면 부품이 아니라 견본이다.

부품을 없앨 때는 대체 부품을 정하고, 규격표에 "다음 판에서 제거"를 달고, 한 판을 기다린 뒤 지운다.
